
# VORTEX LEGENDS API

Servidor multiplayer do Vortex Legends.

## Tecnologias
- Node.js
- Express
- Socket.IO

## Executar
npm install
npm start

## Health check
/health

## Recursos
- Criar sala
- Listar e buscar salas
- Entrar com senha
- Jogadores prontos
- Host
- Iniciar sala
- Expulsar jogador
